# Use the atlas

Start with a question. In specimen mode, orbit a bloom, reset consistently and compare another specimen/fidelity. Observe shape, overlap and texture; framing does not provide scale.

In anatomy, choose flower or orchid before selecting a component. Isolation helps with occlusion; separation explains hierarchy. Restore the intact arrangement before judging attachment. Cutaway is an explicit model explanation, not internal scan recovery.

Pause each reproductive event and read its step. Progress orders explanation, not biological time. Written steps/direct changes keep the concept usable without continuous motion.

Investigations open actual states. Change one control and compare observation with interpretation. Returning to free exploration should preserve context.

Bookmarks stay in this browser. URLs and JSON carry bounded view state. Unsupported imports should give actionable errors. PNG export is a view capture, not measurement.

Keyboard controls/text complement the stage; hover is not the only way to identify a component. If graphics fail, use the guide, component text, investigations and collection.
