# Public source and rights review

The owner authorized public publication of FLORARIA on 2026-09-06. The preparation review covered all seven advertised Git references, ten reachable commits, 280 unique historical blobs, seven published release attachments and the original release archive. It also checked current source files and anonymous access to the runtime dependency distribution.

No strong credential, token or private-key candidates were found in that coverage. History rewriting was not warranted. Pattern checks are evidence of the searches performed, not a guarantee that every possible secret format can be detected. Current source and the final built artifact are checked again before publishing a new release.

All five museum specimens retain item-specific Smithsonian CC0 rights records and locked hashes. The new microscopic views are original educational illustrations and paraphrased, cited explanations; they do not redistribute research figures or claim to be microscopy. The original code and documentation use Apache-2.0. Runtime dependencies retain their actual license notices; LICENSES.md records the shared utility package's metadata/license discrepancy.

The original version-one tag, source, scans, models, investigations and release remain preserved. Obsolete statements about private source and VPS publication have been corrected in current documentation. Operational secrets are supplied outside the repository; visitor code requires none. Personal notebook content stays local or in an explicit user export and is omitted from shared URLs.
