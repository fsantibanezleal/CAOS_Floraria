# Static delivery

The open-source repository delivers a no-login static HTTPS app through GitHub Pages. No runtime Python process, database or paid API is needed.

Build validates/copies the original collection and the microscopic atlas without regenerating evidence. Pages preparation stages direct routes, a browser-compatible CSP and SHA-256 metadata. GitHub Actions publishes the exact checked revision using its scoped deployment token. [Deployment documentation](../../deploy/README.md) owns exact options.

The original VPS release tooling remains available as legacy operational history. Its SSH settings are operator-only, never frontend variables. The Pages release requires no SSH key or visitor credential.

Verify HTTPS, SPA deep links, geometry/catalog requests, source links and exact identity. Upload success or a reachable root is insufficient. Repeat critical controls in both languages/themes.

The initial release tag and all source history are preserved. Re-publishing a prior Pages revision requires explicit selection and the same validation; it does not replace source locks or rerun acquisition. The previous VPS deployment is retired only after fresh Pages verification.
