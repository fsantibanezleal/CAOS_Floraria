# Source and asset ledger

Access date: 2026-09-06. The catalog contains original educational explanations in English and Spanish, with concise named-source references. It does not reproduce source illustrations, copyrighted chapters, or API credentials.

The authoritative `assets.lock.json` pins every returned Smithsonian file. It includes the public file URL, source title, license, policy/API documentation links, CC0-filtered collection evidence, access date, byte count and SHA256. Full automated HTML requests to 3d.si.edu object pages returned HTTP 403 during research; the official indexed CC0 collection and the official 3D API's Open Access declaration supply rights evidence. Public asset downloads succeeded without credentials.

The general Smithsonian catalog API and its 3D file API have different access requirements. This product uses only the public 3D file acquisition endpoint and serves verified local files to visitors. The browser therefore needs neither API keys nor a Smithsonian session.

Use the original Smithsonian titles, including the hybrid sign and cultivar where given. Ranges refer to the concise Smithsonian Gardens exhibit, not an inferred distribution map. Reconstructed separation distances, enlarged pollen/ovules, simplified counts and lifecycle time are teaching choices rather than specimen measurements.

If changing an upstream source or license, revise the lock and supporting evidence deliberately. Never update a hash merely to make a failing acquisition pass. A new or altered asset requires rights, visual and structural review.
